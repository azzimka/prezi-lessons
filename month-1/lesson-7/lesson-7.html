ЗАЧЕМ НУЖЕН PADDING: ДО И ПОСЛЕ

ДО: PADDING: 0; ❌ ТЕСНОТА
Текст карточки прилип вплотную к краям и рамке контейнера.
• Текст упирается в границу блока
• Кнопка выглядит неаккуратно и не воспринимается кнопкой
ПОСЛЕ: PADDING: 14PX 28PX; ✅ ИДЕАЛЬНО
Теперь внутри появился воздух, блок легко сканируется глазами.
⚡ Закон CSS: Фоновый цвет (background-color) элемента всегда заливает область padding!

РАЗДЕЛЬНЫЕ СВОЙСТВА PADDING

СВЕРХУ
padding-top

Отодвигает контент от верхней границы блока вниз.

СПРАВА
padding-right

СНИЗУ
padding-bottom

Отодвигает контент от нижней границы блока вверх.

padding-bottom: 30px;
СЛЕВА
padding-left

Отодвигает текст от левого края (красная строка блока).

padding-left: 20px;

СВОЙСТВО MARGIN: ВНЕШНЯЯ ДИСТАНЦИЯ

БЛОК А (КАРТОЧКА 1)
↕ MARGIN-BOTTOM: 32PX (ДИСТАНЦИЯ)
БЛОК Б (КАРТОЧКА 2)
КЛЮЧЕВЫЕ ПРАВИЛА MARGIN
1
Всегда прозрачен: Margin не имеет цвета и никогда не окрашивается фоном (background) элемента.
2
Отталкивает соседей: Создает чистое пространство снаружи рамки до следующего блока.
3
Не кликабелен: Клик в зону margin не активирует кнопку или ссылку, в отличие от padding.
.card {
  margin-bottom: 32px; /* оттолкнуть соседа снизу */
}

ЦЕНТРИРОВАНИЕ БЛОКОВ: MARGIN: 0 AUTO;

ЗОЛОТАЯ ФОРМУЛА ЦЕНТРИРОВАНИЯ

Как поставить карточку или контейнер ровно по центру экрана без сложных вычислений?

.container {
  width: 600px; /* 1. Обязательна ширина! */
  margin: 0 auto; /* 2. Верх/низ 0, бока auto */
}
⚠️ Критическое правило: Значение auto работает по горизонтали только тогда, когда у блока задана конкретная ширина (width или max-width)!
ШИРИНА ЭКРАНА РОДИТЕЛЯ (100%)
margin-left: auto
БЛОК
WIDTH: 600PX
margin-right: auto
Браузер вычисляет остаток свободного места и делит его поровну между левым и правым краем!

СХЛОПЫВАНИЕ ВЕРТИКАЛЬНЫХ ОТСТУПОВ

ВЕРХНИЙ БЛОК: margin-bottom: 30px;
РЕАЛЬНЫЙ ЗАЗОР = 30PX
(НЕ 50PX!)
НИЖНИЙ БЛОК: margin-top: 20px;
ПОЧЕМУ ОТСТУПЫ НЕ СУММИРУЮТСЯ?

В CSS вертикальные отступы двух соседних блоков схлопываются (Margin Collapse) в один общий отступ.

ПРАВИЛО БРАУЗЕРА:
Браузер выбирает наибольший из двух отступов:
(max(30px, 20px) = 30px) и отбрасывает меньший.
Горизонтальные отступы (лево и право) никогда не схлопываются!

ЗОЛОТОЙ РЕСЕТ: С НЕГО НАЧИНАЕТСЯ ВСЁ

Первые 5 строк каждого CSS-файла в мире:
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
Символ * (звёздочка) выбирает абсолютно все элементы на странице и включает предсказуемый расчет размеров.
ЧТО ДАЁТ ЭТОТ РЕСЕТ?
1. Обнуляет стандартные отступы браузера у <body>, <h1>, <p>, <ul>.
2. Включает режим border-box для всей страницы сразу.
3. Ваши размеры блоков становятся на 100% предсказуемыми.
🚀 С этого момента мы пишем это правило в каждом проекте!

ШПАРГАЛКА: PADDING VS MARGIN

КРИТЕРИЙ PADDING (ВНУТРЕННИЙ) MARGIN (ВНЕШНИЙ)
Где находится? Внутри рамки (border) элемента Снаружи рамки (border) элемента
Фоновый цвет Заливается цветом фона (background) Всегда абсолютно прозрачен
Клик мыши Кликабелен (активирует кнопку/ссылку) Не кликабелен (прозрачная пустота)
Схлопывание Никогда не схлопывается Схлопывается по вертикали (collapse)
Главная цель Создать воздух внутри карточки или кнопки Отодвинуть соседние блоки друг от друга
