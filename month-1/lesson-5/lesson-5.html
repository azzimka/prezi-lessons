Жёсткая структура
Смысл таблицы — в её строгой координатной сетке. Информацию легко интерпретировать, визуально сопоставляя заголовки строк и столбцов.
Интерактивная задача
Найдите в таблице справа личное местоимение 3-го лица, с полом ♀, выступающее в роли объекта.
Пересечение строки «3 Лицо / ♀» и столбца «Объект» даёт ответ: «её»!
Доступность (Accessibility)
При корректной семантической разметке скринридеры озвучивают заголовки ячеек незрячим пользователям без потери контекста.

Словарь тегов таблицы
РАСШИФРОВКА АНГЛИЙСКИХ НАЗВАНИЙ ДЛЯ ЛЕГКОГО ЗАПОМИНАНИЯ
<table> КОНТЕЙНЕР
Table = Таблица
Главный внешний контейнер, открывающий и закрывающий всю таблицу.
<tr> СТРОКА
Table Row = Строка
Горизонтальный ряд. Все ячейки живут строго внутри тега <tr>.
<th> ЗАГОЛОВОК
Table Header = Шапка ячейки
Ячейка-заголовок колонки. Текст внутри жирный и центрирован.
<td> ДАННЫЕ
Table Data = Данные
Стандартная ячейка с фактическими данными (текст, числа, ссылки).
<caption> ПОДПИСЬ
Caption = Заголовок таблицы
Официальное название таблицы. Всегда пишется сразу после <table>.
<thead> ШАПКА
Table Head = Голова
Группирует строки верхних заголовков колонок таблицы.
<tbody> ТЕЛО
Table Body = Тело
Основной массив данных, где находятся рабочие строки таблицы.
<tfoot> ПОДВАЛ
Table Foot = Подвал
Итоговая строка таблицы (суммы, результаты или примечания).

ПРАВИЛА ПОСТРОЕНИЯ
Строка первична
В HTML нельзя просто объявить столбец. Вся таблица верстается строго по строкам сверху вниз.
Три золотых закона:
1. Ячейка никогда не существует вне строки <tr>.
2. В каждой строке должно быть одинаковое количество ячеек.
3. Заголовки <th> автоматически выделяются жирным начертанием.

Смысловые зоны
Как в веб-странице есть header, main и footer, так и в таблице выделяют 3 понятные части.
Зачем делить таблицу:
• Шапка не теряется: когда вы листаете длинный список, названия колонок всегда перед глазами.
• Итоги не путаются: строка «Итого» не перемешается со строками обычных товаров.
• Порядок для браузера: легко оформлять стилями шапку, тело и подвал по отдельности.
<thead> ШАПКА
Верхняя строка с заголовками колонок: сразу понятно, где какой параметр (Товар, Цена, Срок).
<tbody> ОСНОВНЫЕ ДАННЫЕ
Всё содержимое таблицы: строки товаров, расписания, оценок или пользователей.
<tfoot> ИТОГИ И ПОДВАЛ
Нижняя строка с результатами: финальная сумма, средний балл или важное примечание.

Объединение ячеек
Когда ячейка должна занять место нескольких соседей, используются атрибуты colspan и rowspan.
Атрибут colspan (Column Span)
Растягивает ячейку по горизонтали на несколько столбцов: <th colspan="2">.
Атрибут rowspan (Row Span)
Растягивает ячейку по вертикали на несколько строк: <td rowspan="2">.
ПРИМЕР РАБОТЫ АТРИБУТОВ В ЖИВОЙ ТАБЛИЦЕ
Категория (rowspan="2") Параметры (colspan="2")
Тариф Стоимость
Бассейн (rowspan="2") Утренний 1 500 ₽
Безлимитный 3 500 ₽
Итоговый абонемент (colspan="2") 4 500 ₽
Важное правило баланса
Объединённая ячейка «съедает» место следующих ячеек в строке или соседних строках — лишние теги удаляются!
