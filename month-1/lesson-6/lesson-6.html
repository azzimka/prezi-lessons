УРОК 6 · СВОЙСТВА ШРИФТА
Работа со шрифтом
4 КЛЮЧЕВЫХ СВОЙСТВА · БАЗОВЫЙ НАБОР
Свойство Значение Описание Пример в CSS
font-family
имя шрифта Arial serif sans-serif
Задаёт приоритетное семейство шрифтов и список запасных гарнитур (fallback)
p { font-family: Arial, serif; }
font-style
normal italic oblique
Стиль начертания: нормальный прямой шрифт, курсив или наклонный шрифт
p { font-style: italic; }
font-weight
normal bold lighter 100–900
Насыщенность (толщина) шрифта: обычный, полужирный или числовая шкала
p { font-weight: bold; }
font-size
px pt % normal
Размер шрифта: в точных пикселях (px), пунктах печати (pt) или процентах (%)
p { font-size: 30px; }
