4 КЛЮЧЕВЫХ СВОЙСТВА · БАЗОВЫЙ НАБОР
Свойство Значение Описание Пример в CSS
font-family
имя шрифта Arial serif sans-serif
Задаёт приоритетное семейство шрифтов и список запасных гарнитур (fallback)
p { font-family: Arial, serif; }
font-style
normal italic oblique
Стиль начертания: нормальный прямой шрифт, курсив или наклонный шрифт
p { font-style: italic; }
font-weight
normal bold lighter 100–900
Насыщенность (толщина) шрифта: обычный, полужирный или числовая шкала
p { font-weight: bold; }
font-size
px pt % normal
Размер шрифта: в точных пикселях (px), пунктах печати (pt) или процентах (%)
p { font-size: 30px; }

Работа с задним фоном
5 КЛЮЧЕВЫХ СВОЙСТВ
ОСНОВНАЯ КОНЦЕПЦИЯ
Свойства фона в CSS определяют визуальные эффекты и подложку элементов
Фоном может выступать сплошной цвет, изображение или градиент. С помощью CSS можно управлять положением картинки, её повторением и поведением при прокрутке страницы.
Фон применяется как ко всей странице (body), так и к любым отдельным блокам.
КАТАЛОГ СВОЙСТВ ФОНА
background-color Цвет фона элемента
background-image Фоновое изображение url()
background-repeat Повторение по осям X и Y
background-position Положение картинки
background-attachment Фиксация при скролле

Свойство background-color задает цвет фона элемента.

Фоновое изображение: background-image
ФУНКЦИЯ URL()
СИНТАКСИС И ПРАВИЛО
Свойство background-image указывает изображение в качестве фона элемента.
Путь к картинке передаётся через функцию url("путь_к_файлу"). Это может быть как локальный файл, так и внешняя ссылка в интернете.
⚠️ ПОВЕДЕНИЕ ПО УМОЛЧАНИЮ
По умолчанию изображение повторяется (тайлится) как по горизонтали, так и по вертикали, пока полностью не заполнит весь элемент!
style.css
/* Подключаем фоновое изображение */ body { background-image: url("paper.gif"); }
Визуализация эффекта плитки (тайлинг)
Бесшовный повтор картинки
Плиточное заполнение всей области фона

Повторение фона: background-repeat
3 РЕЖИМА ПОВТОРА
ПО ГОРИЗОНТАЛИ
repeat-x
Повтор картинки только слева направо по оси X
→
background-repeat: repeat-x;
ПО ВЕРТИКАЛИ
repeat-y
Повтор картинки только сверху вниз по оси Y
↓
background-repeat: repeat-y;
САМОЕ ЧАСТОЕ
no-repeat
Картинка выводится ровно один раз без размножения
background-repeat: no-repeat;

Положение фона: background-position
КООРДИНАТЫ X И Y
КООРДИНАТНАЯ СЕТКА
Положение задаётся ключевыми словами. Можно указывать по 2 значения сразу: первое по горизонтали (X), второе по вертикали (Y):
left top
center top
right top ★
left center
center
right center
left bottom
center bottom
right bottom
Ключевые слова: left | center | right и top | center | bottom
style.css
body { background-image: url("img_tree.png"); background-repeat: no-repeat; background-position: right top; }
Позиционирование в правый верхний угол
img_tree.png (right top)
Контент страницы расположен слева,
а изображение аккуратно прижато к правому верхнему углу.

Фиксация фона: background-attachment
СКРОЛЛ VS ФИКСАЦИЯ
ПО УМОЛЧАНИЮ
scroll
Фоновое изображение прокручивается вместе со страницей и уходит вверх при скролле.
ПОВЕДЕНИЕ СТРАНИЦЫ
Текст скроллится ↑ Фон уезжает
background-attachment: scroll;
ФИКСИРОВАННЫЙ ЭФФЕКТ
fixed
Чтобы указать, что фоновое изображение должно быть зафиксировано и не прокручиваться вместе с остальной частью страницы, используется значение fixed.
ПАРАЛЛАКС-ЭФФЕКТ
Текст скользит ↕ Фон неподвижен
background-attachment: fixed;

Фиксированный фон: пример кода
СБОРКА ВСЕХ СВОЙСТВ
style.css
body { background-image: url("img_tree.png"); background-repeat: no-repeat; background-position: right top; background-attachment: fixed; }
РАЗБОР СВОЙСТВ ПО ШАГАМ
1
background-image
Подключаем графический файл через url("img_tree.png")
2
background-repeat
Запрещаем дублирование плитки: картинка будет в одном экземпляре
3
background-position
Размещаем строго в правом верхнем углу (right top)
4
background-attachment
Фиксируем (fixed): страница прокручивается, а фоновое дерево остаётся на месте!
