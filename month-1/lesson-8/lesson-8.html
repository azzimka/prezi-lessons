ОСНОВНЫЕ СВОЙСТВА FLEXBOX

ШПАРГАЛКА ПО СВОЙСТВАМ И ЗНАЧЕНИЯМ
01 display
inline block flex
Определяет тип отображения элемента в потоке. Значение flex превращает блок в гибкий контейнер.
КОНТЕЙНЕР
02 justify-content
flex-start center flex-end space-between space-around
Выравнивает и распределяет элементы по горизонтали
ПО ГОРИЗОНТАЛИ
03 align-items
stretch center flex-start flex-end
Выравнивает элементы по вертикали
ПО ВЕРТИКАЛИ
04 flex-direction
row column
Задаёт направление главной оси: в строку (row, по умолчанию) или в колонку (column).
НАПРАВЛЕНИЕ
05 flex-wrap
nowrap wrap
Управляет переносом: в одну строку (nowrap) или с переносом на новые строки (wrap).

ПРАКТИКА: ДВА ЗАДАНИЯ НА FLEXBOX

ЗАДАЧА 01 НАВБАР
ШАПКА САЙТА
LOGO
Разместите логотип слева, а меню со ссылками — справа в одну линию по краям шапки.
  • Сделайте <nav> гибким контейнером
  • Разнесите контент по краям экрана
  • Выровняйте элементы строго по центру вертикали
Свойства для решения:
display: flex justify-content: space-between align-items: center
ЗАДАЧА 02 ЦЕНТРИРОВАНИЕ
ИДЕАЛЬНЫЙ ЦЕНТР
Разместите модальную карточку ровно по центру экрана — одновременно по горизонтали и по вертикали.
  • Задайте контейнеру высоту всего экрана (100vh)
  • Выровняйте карточку по центру главной оси
  • Выровняйте карточку по центру поперечной оси
Свойства для решения:
display: flex justify-content: center align-items: center
