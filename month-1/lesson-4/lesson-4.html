УРОК 4 · INPUT И LABEL
ВВОД ДАННЫХ
<input> и <label>
ОДИНОЧНЫЙ ТЕГ
<input> — непарный, без закрывающего тега. Вы уже знаете это со 2-го урока!
СВЯЗКА FOR ↔ ID
Нажимаете на текст метки — курсор сам прыгает в поле. Это и есть доступность.
index.html
<form> <label for="username">Имя:</label> <input type="text" id="username" placeholder="Введите имя"> </form>
PLACEHOLDER vs VALUE
placeholder — серая подсказка, исчезает при вводе. value — реальное значение поля.

УРОК 4 · TEXTAREA И SELECT
РАСШИРЕННЫЕ ЭЛЕМЕНТЫ
Текст и списки
TEXTAREA
Парный тег — многострочное поле. Для отзывов, комментариев, адреса доставки.
SELECT + OPTION
Выпадающий список — выбор города, страны, тарифа. Компактнее, чем пачка radio.
index.html
<!-- Многострочное поле --> <textarea id="msg" placeholder="Ваш отзыв..."> </textarea> <!-- Выпадающий список --> <select id="city"> <option>Москва</option> <option>Алматы</option> <option>Ташкент</option> </select>
ЗАПОМНИТЕ
<textarea> — парный тег (с закрывающим). <input> — одиночный.

ЗАВЕРШЕНИЕ ФОРМЫ
Кнопка и проверка
BUTTON SUBMIT
Кнопка отправки — собирает все поля и отправляет форму целиком.
REQUIRED — МАГИЯ HTML5
Браузер сам не даст отправить пустое поле и покажет предупреждение. Без JavaScript!
index.html
<form> <label for="email">Email:</label> <input type="email" id="email" required> <button type="submit"> Отправить </button> </form>
ЧТО ДЕЛАЕТ REQUIRED
Попробуйте нажать «Отправить» с пустым полем — браузер покажет: «Заполните это поле».

padding и margin мы изучим позже — пока обходимся без них!
