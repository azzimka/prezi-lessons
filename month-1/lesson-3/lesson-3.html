3 СПОСОБА ПОДКЛЮЧИТЬ CSS

Inline → Internal → External
СПОСОБ 1 style=""
Inline (Встроенный)
<h1 style="color: red;"> Привет! </h1>
✕ Грязная разметка
✕ Нельзя переиспользовать
Ценник на одежде
СПОСОБ 2 <style>
Internal (Внутренний)
<head> <style> h1 { color: red; } </style> </head>
✓ На всю страницу
✕ Только одна страница
Записка к странице
СПОСОБ 3 ВЫБОР ИНДУСТРИИ
External (Внешний) <link>
<link rel="stylesheet" href="style.css">
✓ 1 файл на 100 страниц
✓ Чистый HTML
Гардеробная сайта
СТАНДАРТ Всегда способ №3: <link>
