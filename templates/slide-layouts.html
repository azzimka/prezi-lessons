Работает на вашем компьютере без интернета, сохраняя историю каждой правки.

ЗАКРЕПИТЕ МАТЕРИАЛ НА ПРАКТИКЕ

ЗАДАНИЕ 1 · ИНИЦИАЛИЗАЦИЯ

  1. 01 Создайте новую папку проекта в VS Code.
  2. 02 Откройте встроенный терминал клавишами Ctrl+`.
  3. 03 Введите команду git init.

ЗАДАНИЕ 2 · ПЕРВЫЙ КОММИТ

  1. 01 Создайте файл index.html и добавьте тег h1.
  2. 02 Добавьте файл в индекс: git add .
  3. 03 Зафиксируйте сохранение командой commit.
